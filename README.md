**End-to-End AI Capstone**  
Overview

A web-based AI assistant combining face detection, rule-based dialogue, voice recognition, and command execution.
  
**Features**  
Face detection using face-api.js  
Rule-based chatbot  
Voice commands using the Web Speech API  
Text-based commands  
Dashboard and system-status actions    
Responsive web interface  
Technologies  
HTML  
CSS  
JavaScript  
face-api.js  
Web Speech API  

**How to Run**  
Clone or download this repository.  
Open index.html using VS Code Live Server.  
Allow camera permission.  
Start the camera and click Authenticate.  
Try commands such as hello, help, time, and open dashboard.  
**Important Note** 

This is an educational prototype. Face detection only detects the presence of a face and does not verify identity. The single-file version uses browser-side demo authentication and is not suitable for secure access control.

**Deployment** 

The frontend can be published using GitHub Pages.
